1. Introduction

A data structure is a way of organising data in a computer so that it can be used efficiently. Choosing the right structure directly affects the speed and memory use of a program.

In this assignment we study arrays, linked lists, stacks and queues, and compare their time complexity for insertion, deletion and searching.

The aim is to understand when each structure should be used in real-world applications.
